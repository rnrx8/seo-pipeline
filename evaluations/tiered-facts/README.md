## 再現と採点

`cases.json` / `holdout.json` の期待値は、それぞれのAPI実行前に固定。主な出典は前回のローカル検証で取得済みの公式本文。抜粋は保存本文と空白正規化後に一致することを確認した。その他は明示した架空資料。期待値・難易度タグ・採点理由はモデルに渡さない。同一入力・同一プロンプトで比較し、モデル・推論強度だけを変更。

`run.py` は有料の明示実行用で通常フローから呼ばれない。`summarize.py` はAPIなしの採点用。実応答・usage・台帳はローカル `results/` に保存しgit対象外。再実行時は同じ要求の保存済み成功結果を再利用し、未解決の失敗要求は明示指定なしでは繰り返さない。
