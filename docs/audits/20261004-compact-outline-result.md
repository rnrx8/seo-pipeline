# 指示書としての構成再生成と工程接続の修正

ユーザーは構成を完成本文に近づけず、論点と参照先・必要条件の指示書として扱う方針を承認。Opus5.5で通常の構成生成を再実行し、正常終了した。入力78,136、出力21,255トークン、生成時17,932文字。前回の出力上限中断は再現しなかったが、構成は依然長く、これだけで品質・通常費用の合格とはしない。

## 費用見積もり
Claudeの予約費用が日本語のバイト数をトークン数とする過大見積もりで止まる場合、ツールなしの要求に限ってトークン数計測へ切り替える。10%と4,096トークンの余裕・既存単価上限・最大出力を維持し、同一要求の計測を保存。失敗した計測は自動再試行せず、サーバー検索による入力増大はこの方法で過小評価しない。累計上限は変更していない。

## 接続不具合
通常content_contractがcanonical fact_sheetの「質問文」をサービス名として拾い、構成に存在する6サービスを1件と誤判定。構造補完が質問文を使った無意味なH3を追加した。canonical資料ではrequire_matrixを通し、調査計画の正式candidate_servicesを使用するよう修正。既存資料形式の候補抽出は維持。

文字数配分の見出しが##の場合に既存表を見落とし二重に追加する問題も修正。保存済みoutlineから旧補完関数が加えた文字列との完全一致を確認して、その部分だけ除去。原本をbefore-handoff-fixへ保存し、通常の構造契約作成・構造検査を再実行。新たなAI生成や執筆内容の手動変更はない。構造確認は合格、修正後17,253文字。

## 内容判定と停止
構成の意味確認は不合格。無料初回メッセージと継続課金の混同、アネモネの更新停止後利用期限の根拠不足、第三者由来の機能まで公式情報とする注釈、ヒールメイトのプレミアム機能と比較料金の条件不一致が指摘された。網羅性・統計の範囲・未完成情報・無限定の安全保証は当該確認で合格。

誤った補完状態から後続の修正・執筆を進めないため確認中に停止。進行中だった1呼出しは費用不明として予約を残す。research_validationは修正後構成の再確認待ちとして無効化。調査全体合格は保存し、本文執筆は未着手。本番反映なし。

ネットワーク禁止393テスト合格。構造対象の誤認、配分表の重複、費用計測後も上限を維持することを回帰検証。今回の計上分$1.053228625（約211円）、中断1呼出しの未確定予約$0.705315（約141円）。台帳累計$9.624193075（過去の不明分予約を含む約1,925円）、残り約75円。上限を解除していない。

次の有料工程は構成の指摘箇所修正と再確認。全調査や構成の全文新規生成に戻らない。今回の短縮で品質が落ちないと結論づける段階ではない。
