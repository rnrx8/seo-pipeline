# 300字連続制限の確認

追加の有料生成や本番アクセスは行わず、既存の処理と保存済み記事を確認した。

- 執筆指示：H2/H3/H4の通常文章が300字を超えて連続したら表・リスト・H4で整理。
- 機械検査：空行、改行、太字、HTML装飾だけでは連続をリセットしない。300字は許容し、301字以上を検出。Markdown装飾・空白・リンク先URLは文字数から除外し、リンク表示文は数える。
- 内容監査：モデルが全項目passでも機械検査の指摘があればvalid=false。
- 局所修正：修正後にも同じ検査を行い、残存時は合格にしない。
- 最終検証：完成本文へ再度同じ検査を実施し、残存時は完成判定を拒否。

保存済み本文を現行検出器で再検査した最大連続文字数：

| 本文 | 最大連続文字数 | 300字超 |
|---|---:|---|
| 最初の冒頭生成テスト | 175 | なし |
| 読者ニーズ修正後の冒頭生成テスト | 229 | なし |
| 完成記事のローカル保存版 | 272 | なし |

機械判定は通常文章の連続が対象。表セルやリスト項目自体の長さ・形式の適切さは既存のorganization担当で確認し、同じ300字カウントを適用する処理ではない。画面上の折返し・スクロール量の実ブラウザ確認は今回行っていない。

H3が200字以上という条件とは両立する。H3全体は200字以上にしつつ、表・リスト等を挟んで通常文章の連続を300字以内にする。H4配下もそれぞれ検査対象。

モデルの全項目pass応答を模擬しても342字の連続文章を不合格にする回帰テストを追加。外部通信遮断下で445件通過。実モデルレビューの有効性や本番デプロイ状態まで確認した結果ではない。
