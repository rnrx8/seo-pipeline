# 根拠採用情報と執筆情報の分離（2026-10-06）

原因：generation_context.decision_bundleはmatrixからreason/basis等を回答と同じdecisions行にコピーしていた。保存済み構成にも「第三者掲載と明記」という本文指定が残る。本文での特定語禁止を追加しても、構成と入力資料が逆方向の指示になっていた。

変更：
- decisionsからreason/basis/確認フラグ/調査優先理由/採用に必要な出典種別を除外。未採用項目はpublishableで区別する。
- 日付や使用条件が混在する既存applicable_atは失わずusage_constraintsへ分離。省略理由も制約として保持。現在の結論に使えるかのフラグも維持。
- sourcesはURL/原文/専門家名・資格等の対応を維持し、出典独立グループや採用種別・専門性判断理由を執筆用から除外。
- 調査のanswerは対象・期間・条件を含む回答事実、採用経緯は管理フィールドに分けるよう生成元も変更。
- 元のmatrix・引用・監査資料は無改変。URLの表示は既存citation_styleに従い、第三者情報を公式発表と偽る処理は追加していない。

適用：focusedのgeneration_evidence経由の構成・本文・サービス配置で共通。旧非focusedのwriting_evidence経路は今回変更していない。

限界：過去にanswerや構成本文へ混入済みの採用経緯を自動判別して削除しない。applicable_atの古い記録は時点保護のため制約として残る。新しい入力分離だけで漏出ゼロを証明したものではない。旧構成をそのまま使う試験は根本修正の検証にならないので、次は新しい資料境界で構成から検証する。研究ポリシー照合を迂回して旧matrixを合格扱いにすることはしない。

外部通信遮断下446件通過。採用理由を執筆資料に含めないこと、日付・比較条件・URL・原文・元matrixを保持することを確認。追加API費用・実生成・本番反映なし。
