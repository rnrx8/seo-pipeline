## 実装

1. AIの必須分類を訂正できるようにした。独立した計画確認で具体的に指摘されたIDだけに限定して、重要度の変更・不要義務の削除を候補として許す。候補を採用する前に既存の2回目の独立確認で元のユーザー設定・検索意図と照合し、不合格なら旧計画を維持する。ユーザー指定を捨てる許可ではない。指摘されていない必須項目の降格は禁止のまま。追加モデル工程はない。
2. 単一サービスのプラン比較とサービス同士の比較を分けた。候補が2件未満の場合も、推測で2〜3サービスを必須にせず検索意図に沿った比較内容を既存の網羅性確認へ渡す。サービス間比較の機械的な最低数も一律3件から2件へ変更。明示されたN選の数・検索意図に必要な候補の網羅は別の既存確認で維持。
3. 上限のみ・以内・以下の文字数指定から最低文字数を生成しない。目標や範囲の指定は従来の扱いを維持。上限だけの設定に110%の余裕を上乗せしない。
4. 小見出しの40字下限を廃止し、本当に本文が空の章を機械的に検出。短い回答の意味的な充足は既存の内容確認で判断する。
5. 表内の未確認等を単語部分一致で不合格にしない。セル全体が未確認/要確認/TBD等の仮置きの場合は引き続き検出。文章としての根拠不足や執筆メモは既存の内容確認対象。
6. 比較章の見出しに「比較・おすすめ・ランキング・一覧」の語を強制しない。対象数・本文の比較内容・説明の充足は既存の確認へ渡す。
