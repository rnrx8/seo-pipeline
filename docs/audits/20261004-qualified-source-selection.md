# 条件と時点を限定した第三者料金の採用

ユーザーの明示承認に従い、共通採用基準を intent-evidence-v5-qualified-source-selection に更新。以前の「採用範囲を限定しても第三者資料間の重要な矛盾が残れば不合格」という一律停止を置き換えた。

## 実装
料金は対象、プラン、契約期間、総額、月額換算、決済方法、キャンペーン条件で区別する。独立した具体的な料金表2件が同条件・同額なら、その資料の掲載情報として時点と条件を限定して採用できる。異なる第三者記事の存在や単なる更新日の新しさだけで差し戻さない。3件目の資料、全資料の一致、改定日の特定は必須にしない。より新しい公式料金・改定告知・条件誤読などの具体的な反証は優先する。

既存のanswer/applicable_at/reason/evidenceへ対象条件、採用元の公開・更新日（不明可）、確認日、選択理由を残す。既定の注釈へ引き継ぎ、表や章単位でまとめて表示できる。出典の更新日を料金の適用開始日に置き換えない。既存の共通基準を通じて計画、調査、執筆、最終確認へ反映し、後段で金額差だけを理由に差し戻さない。新しい工程・検索回数・OCR・モデル呼出しは追加していない。

## 保存資料の確認
ガチとら（https://gachitora.jp/apps/marriedgo.php）とRooters（https://www.team-rooters.com/matching-info/news/1563）の保存本文はいずれも男性スタンダードの1ヶ月6,480円、3ヶ月一括14,940円（月額換算4,980円）を掲載。Rootersは2026/09/19の更新表示がある。ガチとらの保存本文に公開・更新日は確認できないため推測せず、2026-10-04 JSTの取得確認日で扱う。別の資料は1ヶ月4,980円と明記しており、単なる契約期間の誤読だけではない。

この確認は料金採用候補の整理であり、独立性の実モデル再判定や保存済み調査の合格を代行しない。記事・調査台帳を手動で合格に変更していない。

## 検証と残作業
ネットワーク禁止388テストに合格。別料金の第三者資料を残したまま、採用した条件・注釈用日付・選択理由が通常の執筆資料へ渡ることを検証。同一原典の2件では不合格になる検査も維持。モデルが新基準で正しく判断することはこのオフライン検証だけでは証明できない。
