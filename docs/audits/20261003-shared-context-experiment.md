## 設計上の判断

- **今回の共有形式をそのまま本番に入れない。** 6万以内にならず、参照形式の複雑さが増える。圧縮を増やすだけの開発はここで止める。
- **291円を今後の予想費用として使わない。** Solの入力6万だけでなく、合計出力37,100から10,000へ収めるという未検証の前提もあった。
- 次の設計は「全対象資料を高いモデルで再読すること」を前提から外す。既に確認した事実・条件・出典と、今回解決する必要のある問題を分ける。
- 根拠不足には不足資料の取得、明確な矛盾には関連する複数根拠の比較を割り当てる。資料が増えていないのに同じ内容を高いモデルに再送し続けない。
- 確認済み事実の継承には、引用本文・条件・時点の対応と、資料変更時の失効が必要。未確認を確認済みにする方法にはしない。
- 文章・整合性・表示の担当分割は維持する。今回これらのモデルは変更していない。

この試作で完了したのは「出典を落とさない単純共有だけで6万にできるか」の判定。答えは不可。
300円以内の完成見込み、低価格モデルへ担当を変更した際の品質、通常フローの記事完成は引き続き未検証。
