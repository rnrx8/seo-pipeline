# 補助情報の省略と公式取得失敗

同じ実行中に残存条件を監査し、major_sources_checked が公式本文の取得成功を必須にしていたことを確認した。第三者本文を読んでいても、公式が取得できなければ補助情報を省略できないという過剰な条件だった。

公式確認の試行が記録され、対象質問に紐づく第三者引用が実際の取得本文と一致する場合にも、省略候補を許可する。単なる取得失敗、未訪問URL、無関係な本文だけでは許可しない。必須項目の省略は禁止を維持し、記事全体の網羅性判断も維持する。これは事実の採用条件を変更せず、未確認回答は執筆用資料に出さない。既存の省略前根拠の保存欄を利用し、新しいモデル工程や検索を追加しない。

ネットワークを禁止した385テストに合格。取得失敗＋第三者本文の確認で省略できること、全体確認で拒否できること、無関係な本文に差し替えたら拒否することを確認。

並行中の有料テストは6c082efの読み込み済みコードで動作しているため、この修正の実モデル検証とは区別する。記事完成・本番反映は未確認。
