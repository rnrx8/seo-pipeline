## 変更した接続

| 対象 | 変更後 |
|---|---|
| 構成・本文の確認 | 全体を読んで主張と条件を判断し、未解決箇所の段落ID・調査項目ID・必要URLを返す。対象不明なら全資料に戻さない |
| 原文照合 | 指定された論点の資料と、対象段落・近傍・上位見出しだけを渡す。比較表内の全リンクを根拠資料として自動選択しない |
| 追加照合 | Lunaが具体的に未解決とした場合に限る。比較語の文字列検出と文章ハッシュによる通常実行内の抜き取りを削除。資料が不足しても全資料集合へは戻さない |
| 確認結果の引き継ぎ | 既存の照合応答に、対象・条件・資料・日付・確認方針に結び付いた結果を保存。次の確認入力へ渡す。同一範囲は再送せず再利用。元の調査回答を根拠なく書き換えない |
| 修正 | 構成も本文も共通の範囲選択を使う。対象段落・関連資料を限定し、対象外の編集は適用しない。本文の集約結果でも調査項目IDとURLを失わない |
| 再開 | 保存応答の過去版も再利用。通算回数・処理種別・対象・使用資料を既存費用台帳へ記録。再開や直接の修正関数呼出しで回数・費用枠を増やさない |
| 予定外の拡張 | 修正後に新しい原文照合の論点・資料が増えた場合は、原因確認前に追加送信しない |
| 不合格・未完了 | 未解決の比較条件を、別の事実項目の合格で上書きしない。不合格の確認結果は、再開しても不合格のまま |

完成本文の5担当（事実、網羅性、文章、全体整合性、表示整理）は維持した。全文での文章・整合性確認と、原文の対象限定照合を分けている。

旧`repair_context`の資料選択処理を削除し、共通の`review_scope`へ置換した。新旧の資料選択を二重実行していない。生成モデル、検索意図・採用基準・税込み等の合意済み方針は変更していない。

## 費用制御と、まだ言えないこと

- 通常の品質確認総枠は既存の$1.25を維持。既存の換算基準200円/USDでは250円で、300円目標内の安全枠。生成は別枠。
- このうち構成確認・修正・照合は最大$0.50、本文確認・修正・照合は最大$0.75の送信前制御とした。これは**消費を制限する配分であり、完走費用の予測ではない**。
- 完了検証モードでもこの段階別制限は解除しない。回数・配分は台帳に保存し、コード設定だけで暗黙に変更しない。
- 構成全体確認は通算2回、構成修正は1回。本文の各担当は2回、本文修正は形式不備の再提出を含め2回まで。原文照合・独立確認・指定原文の拡張も、それぞれ段階ごとに2要求まで。未確定の同一要求は自動再送しない。
- 実データの最初の構成確認は、文字バイト数をトークン上限として扱う保守的算定だと約127円。構成段階100円の枠より大きいため、既存の入力トークン計測による精密化が必要になる。今回は外部計測をしていない。**この時点で「100円で構成完了」「250円で確認完走」とは言えない。**
- 原文照合や修正の要求は小さくなったが、本文は未生成であり、完成本文の全要求量や実際の修正回数は未確定。入力サイズの削減率を総費用の削減率として報告しない。
- 旧方式で費用を消費済みの台帳には、新方式の回数や段階予算を勝手に追加付与しない。旧履歴を見つけたら移行確認前に停止する。既存の約3,026円の台帳は保持している。

## オフラインで検証できたこと

通信接続を遮断して全422件が通過。Pythonの構文確認と差分の形式確認も通過。

今回追加した15件では、次を確認した。

1. 同じ主張の表・説明・結論を対象にし、無関係のサービス資料を送らない。
2. 比較表のリンクだけで全サービス資料へ拡大しない。
3. 指定範囲が無い、架空の資料ID、対象外編集を拒否する。
4. 同一の原文照合を再開してもモデル要求を追加しない。
5. 別サービスの変更では確認結果が残り、対象条件・原文の版が変われば再確認対象になる。
6. 同じ段落でも違う疑問に古い合格を流用しない。
7. 不合格を再開時に合格へ変えない。
8. 修正関数を直接呼んでも、通算回数制限を回避できない。
9. 完了検証モードでも段階予算を越えない。
10. 未確定の課金要求を再送しない。旧方式の使用済み予算をリセットしない。
11. 複数版の応答を保存し、過去の同一要求も再購入しない。
12. 本文の確認結果から修正入力へ、対象論点と出典が引き継がれる。
13. 通常の構成確認→修正→再確認→再開を通し、再開時の追加要求が0件になる。
14. 修正後の新規論点を自動購入しない。
15. 未完了の比較確認は未完了として残る。原文変更時に本文の事実判定要求も無効化する。

モデルの応答は固定したテストデータを使用した。モデルの判断精度・新しい指示への遵守率・完成記事の読みやすさを証明するものではない。旧テストのうち、全資料への拡大や無条件の追加照合を期待していたものは、今回承認された動作へ更新した。
