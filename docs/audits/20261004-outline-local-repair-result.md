# 構成の局所修正と再確認の入力重複除去

## 実装

research_validation不合格時の全文構成再生成を、既存ブロックIDによる一度の局所修正へ変更。調査合格をrequire_matrixで確認し、確認済み回答と条件・出典の指示書用資料を渡す。原資料全文の再送や新しい調査を追加しない。修正前を保存し、修正後のresearch_validationを無効化して独立再確認へ進む。モデルによる見出し階層変更は適用前に拒否する。

構成監査のconditional_factsが、research_decisionsにある回答とほぼ同じ内容を約79,519文字再送していた。validな調査回答のfacts_sha256と現在の事実が一致するときだけ、索引の再送を回答参照に置換。実際の対象・プラン・期間等の情報はresearch_decisionsに保持。不一致・旧形式・非compact経路は従来どおり条件索引を渡す。機械検査のscope_issuesは原資料で実行を継続。
